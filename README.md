The Meridian Archive — a complete top-down stealth game in three floors of a night archive. You are Wren, a courier with one night to take back nine sealed files and leave unseen. Guards patrol fixed routes and watch through vision cones, cameras sweep the halls, shelves and crates and plants hide you, lamplight gives you away, and a suspicion system lets you be noticed, chased, lost and found again. Throw coins to distract a guard, sneak in the dark, and slip out the green exit.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD or arrows to move, Shift to sneak, Q or click to throw a coin, P to pause. No build step, no network requests: the whole game is static files under `game/`.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
